# 🚀 How to Deploy a Project to GitHub Pages

This guide explains how to deploy to **GitHub Pages** using a simple workflow.

---

## 📌 Deployment Steps

1. Switch to the **main** branch:

```bash
git checkout main
```

2. Install project dependencies:

```bash
npm i
```

3. Build the production version of the app:

```bash
npm run build
```

4. Deploy the build output to GitHub Pages:

```bash
npm run deploy
```

5. Visit page

```bash
https://devboomgames.github.io/privacy_policy/
```
